# Tic-Tac-Toe (Python)

A simple **two-player Tic-Tac-Toe** game with a clickable window, built with Python's standard **Tkinter** library.

## Requirements

- Python 3 with Tkinter (included in most Windows and macOS Python installations)

## Run

Clone or download this repository, then open a terminal in its folder:

```bash
python tictactoe.py
```

If your system uses `python3`, run `python3 tictactoe.py` instead.

## How to play

- Player **X** goes first.
- Players take turns clicking empty squares.
- Get three marks in a row, column, or diagonal to win.
- If all nine squares fill without a winner, it's a draw.
- Click **Restart Game** to play again.

No third-party Python packages are required.
